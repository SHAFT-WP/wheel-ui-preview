REV.0.2 Geometry Definition

Bomb Profile의 Roll-in 궤적과 MAP을 사용한다. Roll-in 시작점에서 Target이 정확히 우현 90°가 되도록 xroll + MAP·cos ψ = 0을 풀어 ψ를 산출한다. Wheel Range는 yroll + MAP·sin ψ이다. 따라서 기존 자료에서 서로 충돌하던 ARC/RIP ±0.5 NM 고정 보정은 사용하지 않는다. 운용 흐름은 Target Sorting → Arcing → 1st Attack Run → N+1 Attack Run으로 유지한다.
